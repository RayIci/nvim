# Spec Delta

## REMOVED Requirements

### Requirement: Theme format
**Reason**: The theme engine and studio moved to their own repository (RayIci/vale.nvim); this configuration no longer specifies their behaviour.
**Migration**: The requirement is carried over into `openspec/specs/vale-engine/spec.md` in RayIci/vale.nvim and amended there: bundled themes ship with the plugin and are read-only (editing one copies it into the user themes directory first), and user themes and their generated loaders live in a configurable directory that defaults to the Neovim configuration directory. The configuration-side wiring is specified by `ui-shell` (Vale theme plugin wiring).
